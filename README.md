# 宅建 直前総復習

宅建試験の頻出論点を○×で総復習するアプリです。スマホのホーム画面に追加すると、電波のない場所でも使えます。

- 全分野・282問（権利関係、法令上の制限、税・価格、宅建業法、5問免除）
- 得点力の目安：○×の直近の正答率と、本試験の論点別出題数（令和5〜7年度からの概算）から推定
- 頻出論点 集中チェック：期待失点（年間出題数 × 推定誤答率）の大きい論点から出題
- 記憶定着：誤答回数・忘れ戻り・まぐれ申告を記録。日を変えて2回続けて正解すると「定着」
- 最終決戦：まちがえた論点の解説を Claude に頼むプロンプトを作成してコピー
- 数字まとめ（隠して暗記チェック）、要点チェック、今日の総復習、分野別
- 同じ論点の問題が続かないように出題（前の問題の解説がヒントにならないように）
- 学習記録の引っ越し（コピー＆貼り付けで、別の端末や Artifact 版との間で移せる）
- 学習記録は端末の中だけに保存されます

## 問題について

- 問題・解説はすべてオリジナルです。令和5〜7年度の本試験で繰り返し出題されている論点を参考に、条文・制度から作成しました。過去問の文章は使っていません。
- 法令は 2026年4月1日時点の内容にもとづいています。誤りが残っている可能性があるため、各問の根拠条文で確認してください。
- 本物の過去問は [不動産適正取引推進機構（RETIO）](https://www.retio.or.jp/exam/past_ques_ans/other/) で公開されています。

## 更新のしかた

1. 問題の追加・修正は `questions.js`
2. `node scripts/check.js` でチェック（形式・○×と解説の食い違い・バランス）
3. 内容を見直し、`docs/見直し記録.md` に記録
4. `sw.js` の `VERSION` を1つ上げる
5. Claude の Artifact 版も更新する場合は `node scripts/build_artifact.js`（`dist/` に出力。リポジトリには含めない）
