# 宅建 模擬問題アプリ 設計メモ

作成日: 2026-10-12

## 1. 著作権の方針

参照元: 不動産適正取引推進機構(RETIO)「宅建試験の問題及び正解番号表」
https://www.retio.or.jp/exam/past_ques_ans/other/

RETIO「著作権・免責事項」(https://www.retio.or.jp/copyright/) の要旨:
- 掲載情報は著作権保護の対象
- 私的使用・引用など著作権法上認められた行為を除き、無断転載・無断改変は不可

これを受けて、このアプリは次のルールで作る。

| やること | やらないこと |
|---|---|
| 過去問PDFを手元で読み、**どの論点がよく出るか**だけを集計する(私的使用) | 問題文・選択肢・解説をアプリに入れる |
| 問題文・解説は**条文・制度の事実から新しく書き下ろす** | 過去問の文章を言い換える・語尾だけ変える |
| 各問に根拠条文(例: 宅建業法37条1項)を書く | 「令和○年 問○」のような出典の対応表を収録する |
| 公式サイトへのリンクを「本物の過去問はこちら」として置く | PDFをリポジトリに含める・再配布する |

- 過去問PDFはスクラッチパッド(一時フォルダ)にだけ保存し、プロジェクトには入れない。
- 法令の条文、数字(「2年以上」「8日間」など)、制度の仕組みは事実なので、著作権の対象にならない。

## 2. 出題傾向の分析(令和5〜7年度・計150問)

R3・R4のPDFは画像(スキャン)のため、文字を取り出せなかった。R5〜R7の3年分を分析した。
分類は筆者の判断による概数。

### 試験の構成(毎年ほぼ同じ)

| 分野 | 問題番号 | 問題数 |
|---|---|---|
| 権利関係 | 問1〜14 | 14 |
| 法令上の制限 | 問15〜22 | 8 |
| 税・価格評定 | 問23〜25 | 3 |
| 宅建業法 | 問26〜45 | 20 |
| 5問免除科目 | 問46〜50 | 5 |

### 毎年必ず出る論点(3年とも出題)

- **権利関係**: 借地(問11)、借家(問12)、区分所有法(問13)、不動産登記法(問14)、賃貸借、共有、相続、契約不適合責任(売買)
- **法令上の制限**: 都市計画法(2問)、建築基準法(2問)、盛土規制法(旧 宅地造成等規制法)、土地区画整理法、農地法、国土利用計画法(各1問)
- **税・価格**: 不動産の鑑定評価(問25)。税金は1年に2税目がローテーション(印紙税、不動産取得税、登録免許税、固定資産税、住宅ローン控除)
- **5問免除**: 住宅金融支援機構、景品表示法(広告)、統計、土地、建物(毎年各1問)

### 宅建業法20問の内訳(3年計60問)

| 論点 | 3年の出題数 | 優先度 |
|---|---|---|
| 業務上の規制(禁止行為・従業者証明書・帳簿・案内所など) | 約16 | ★★★ |
| 35条 重要事項説明 | 8 | ★★★ |
| 自ら売主の8種制限(クーリング・オフ、手付、契約不適合など) | 6 | ★★★ |
| 37条書面 | 5〜6 | ★★★ |
| 営業保証金・保証協会 | 5 | ★★ |
| 免許 | 4 | ★★ |
| 宅建士(登録・宅建士証) | 4 | ★★ |
| 媒介契約 | 4 | ★★ |
| 報酬 | 3 | ★★ |
| 広告 | 2〜3 | ★ |
| 住宅瑕疵担保履行法 | 3 | ★(毎年1問) |

### 民法の傾向

毎年テーマが入れ替わる。3年間で出たのは、意思表示、制限行為能力、代理・法律行為、時効、物権変動(対抗要件)、共有、相隣関係、抵当権、保証・連帯債務、相殺、債務不履行、契約不適合、賃貸借、委任・請負、相続(代襲・配偶者居住権)。範囲が広いので、基本論点を薄く広く出題する。

## 3. アプリの設計

### 基本方針
- 既存の [takken-35-37](../../takken-35-37/) と同じ構成にする(1ファイルの PWA、オフライン対応、GitHub Pages で公開)
- 問題データは `questions.js` に分けて、追加しやすくする

### 問題データの形式(案)

```js
{
  id: "gyo-37-001",
  field: "宅建業法",            // 権利関係 / 法令上の制限 / 税・価格 / 宅建業法 / 免除科目
  topic: "37条書面",
  type: "tf",                  // tf = ○×、choice4 = 4択
  q: "(自作の問題文)",
  choices: [],                 // 4択のときだけ
  answer: true,                // ○×は true/false、4択は 0〜3
  explain: "(自作の解説)",
  basis: "宅建業法37条1項",    // 根拠条文
  lawAsOf: "2026-04-01"        // どの時点の法令を基準にしたか
}
```

### 学習モード
1. **分野・論点別ドリル**: 論点を選んで○×を連続で解く(通勤中に使いやすい)
2. **ミニ模試**: 10問をランダムに出題(4択)
3. **本試験形式**: 本試験と同じ分野配分で50問、2時間のタイマー付き(問題が十分に増えてから)
4. **苦手復習**: 間違えた問題だけを出題
5. **成績**: 分野別・論点別の正答率を表示(端末内に保存)

### 問題数の目標(本試験の配分 × 約3倍)

| 分野 | 目標 |
|---|---|
| 権利関係 | 42問 |
| 法令上の制限 | 24問 |
| 税・価格 | 9問 |
| 宅建業法 | 60問 |
| 5問免除科目 | 15問(統計は毎年変わるので除外) |
| 合計 | 約150問 |

## 4. 注意点・リスク

- **問題の正確さ**: 問題は Claude が書き下ろすので、誤りが混じるおそれがある。各問に根拠条文を書いて確認できるようにし、法令の基準日も記録する。
- **法改正**: 毎年4月1日時点の法令が出題範囲になる。年1回、見直しが必要。
- **統計問題**: 毎年数字が変わるため、収録しない(公式の資料を案内するだけにする)。

## 5. 費用(課金)

**すべて無料で作れる見込み。**

| 項目 | 費用 |
|---|---|
| 過去問PDFの閲覧・ダウンロード | 無料(RETIO公式) |
| 開発に使う道具(pypdfium2 など。スクラッチパッドにだけ導入) | 無料 |
| アプリの動作(サーバー・API・AIの呼び出しは使わない) | 無料 |
| GitHub Pages での公開(公開リポジトリ) | 無料 |

有料になる可能性があるもの(今回は使わない): 独自ドメインの取得、非公開リポジトリでの Pages 公開(GitHub の有料プラン)、アプリ内からの AI API の呼び出し。

## 6. 段階計画

1. **試作**: 宅建業法の最重要4論点(35条・37条・8種制限・業務規制)から ○×問題を20問作り、ドリルモードだけ動かす
2. **確認**: スマホで操作感を確認し、問題の内容をレビューする
3. **拡充**: 残りの分野の問題を追加し、4択とミニ模試を加える
4. **仕上げ**: 苦手復習・成績・本試験形式を加え、PWA にして GitHub Pages で公開する
